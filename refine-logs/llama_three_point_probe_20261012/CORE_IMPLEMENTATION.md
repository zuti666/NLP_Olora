# Three-point probe implementation

`src/optimer_three_point_probe.py:ThreePointProbe` shares only optimizer delegation, parameter validation and restoration helpers with `TwoPointProbe`. Its `step` evaluates BASE, BASE+rho*g0/(norm(g0)+eps), and BASE-rho*g0/(norm(g0)+eps). Both points are constructed from the same frozen clean gradient and original BASE, independent of the final mode and learning rate. The native Trainer owns global mean reduction and per-microbatch RNG replay; standalone closures replay the complete BASE RNG and controlled state.

Modes: `g1_plus` submits gplus; `backward_reflected` submits 2*g0-gminus; `central` submits g0+0.5*(gplus-gminus), without dividing by rho; `g0` submits only g0. Every mode performs three CE gradient phases and two replays even at zero radius or zero gradient. Before the unique real HF AdamW commit, the implementation restores BASE exactly and clips the selected gradient once. No g2/g3, Fisher, history, projection or HVP is computed.

Diagnostics include both actual probe displacements, gradient norms and cosines, forward/reflected response cosine, symmetric response (gplus-gminus)/2 and even response (gplus+gminus-2*g0)/2. The legacy `probe_g1_*` compatibility fields explicitly reference gplus; the legacy response fields explicitly describe submitted-minus-g0. `probe_sign=0` marks the paired protocol, and `probe_signs=[1,-1]` records the two actual signs. Sampled BF16 parameter-cast diagnostics are observational and explicitly do not prove actual forward visibility.

A failed second-side probe or partially executed commit restores trainables, entry gradients, RNG, supported forward buffers/caches/flags, optimizer moments and update counters. Frozen backbones are immutable by contract and guarded with shared version checks. Checkpoints use distinct `_three_point_probe` metadata and reject different modes, protocol, geometry or commit backends.

CPU validation: 18 tests passed. Independent nonlinear analytic oracles check all modes with and without precomputed g0; central equals the arithmetic average of forward and reflected raw gradients and cancels even response terms. Further tests cover equal mode budgets and probe points, LR independence, zero radius/gradient, missing-gradient masks, same RNG/dropout and controlled buffers, one clipped HF AdamW commit, failed second side/partial commit rollback, BF16 proxy invariance and checkpoint continuation. No GPU action was performed by this agent.
