# 反向探针差分直接回加：独立实验计划

**日期：**2026-10-03T18:21:51.222119+02:00。

**问题：**下降侧读取的梯度本身与符号修正后的差分回加，是否产生不同的持续学习效果？本轮只执行一个新正式设置、seed2；原P/C/CD最终实验独立继续。

## 方法定义

同批数据、同增强、同一前向随机状态R0，所有可训练LoRA A/B与seen FC一起构成参数θ：

\[
g_0=\nabla L(\theta_0),\qquad u_0=\frac{g_0}{\|g_0\|+10^{-12}},
\quad\theta_-=\theta_0-0.05u_0,\quad g_1'=g_-=\nabla L(\theta_-),
\]
\[
\boxed{U=g_0+(g_0-g_-),\qquad\theta_{new}=\theta_0-\eta U.}
\]

负侧探针按历史SAM/GAM协议使用N(g0)，不使用未经单位化的原始g0；若改成θ−ρg0，实际采样距离会随梯度范数变化，是另一个实验。本轮修正系数固定1，不除以ρ、不归一化修正或最终U。先恢复θ0，再从θ0提交一次SGD；绝不从θ−处提交，也不在参数上先做一个真实下降步。

训练每步仅两次普通CE反传：g0和g−。不计算g+/g2/g3。内层ρ=.05；没有外层r，兼容配置gam_grad_norm_rho=0.0表示禁用，输出outer_radius=null。method_name=reverse_probe_reflected_v1，probe_branch=backward_local，update_direction=g0_plus_g0_minus_g1minus。

## 为什么可行，与SAM/旧实验的关系

记H=∇²L(θ0)。在固定随机函数、光滑局部邻域和固定本步u0下：g±=g0±ρHu0+O(ρ²)。因此g+−g0是ρHu0的向量近似；除以ρ后才对应Hu0的有限差分近似，并不是完整Hessian矩阵。

由负侧得到g0−g−=ρHu0+O(ρ²)，故本次U=g0+ρHu0+O(ρ²)。标准一阶SAM最终用g+=g0+ρHu0+O(ρ²)。两者在小ρ的一阶项一致，但非线性模型中并不完全相等。精确差异为U−g+=2g0−g−−g+；在关于训练参数的二次损失上，实数算术下两者完全相同。只用负侧梯度g−则含相反的一阶修正g0−ρHu0。

这是由本轮定义作出的局部Taylor分析，不是泛化效果证明，也没有保证每步下降、对SAM目标的精确梯度或算法新颖性声明。标准SAM使用正向损失上升探针的实现依据见 [SAM原文，算法1及式(3)](https://arxiv.org/pdf/2010.01412)；旧GAM的外点读取/梯度差分结构见 [GAM原文，附录D](https://arxiv.org/html/2303.03108v3#A4)。

| 设置 | 探针及位置 | 最终更新U | 这次关系 |
|---|---|---|---|
| 旧仅g1′ | g−=g(θ0−ρN(g0)) | g− | 保留了负号曲率响应 |
| 旧反向外层D | g2′=g(θ0+rN(g−−g0)) | g2′，若该行最终方向是g2 | 差分只选外点，r=1；不能与仅g1′行混为一组 |
| 旧反向符号修正外层C | g2C=g(θ0+rN(g0−g−)) | g2C | 和新方法使用同符号差分，但外层单位化、外点读取不同 |
| 本次反向差分回加 | g0、g−两次读取 | g0+(g0−g−) | 不构造外点，保留差分幅度 |
| 标准一阶SAM方向 | g+=g(θ0+ρN(g0)) | g+ | 仅作局部理论参照，本轮不新增整条SAM训练 |

若旧“仅g1′”实现仍额外计算g2′，在状态/RNG严格恢复且最终只用g1′的前提下，外层r不应影响其更新；外层探针仅是额外执行。必须以实际最终direction判断，不能只看定义了哪个中间梯度。

原Local-CD计划中的L03已包含同一更新：g0+(λH/h)(g0−g−)，当h=λH=.05时就是本次系数1；当时suite.jobs为空、没有正式成绩。本轮仅独立启用这个公式，用两探针实现；原六组方法与匹配控制仍仅保留计划。

## 冻结实验设置

| 项目 | 设置 |
|---|---|
| 数据 | ImageNet-A，本地train5981/test1519，类顺序0…199，10×20类 |
| 模型 | ViT-B/16 augreg2_in21k_ft_in1k预训练；骨干冻结，Q/V LoRA rank10及seen FC训练；无alpha/rank缩放 |
| 随机性 | seed2；数据顺序/增强沿用冻结确定性协议；同一步两探针重放R0，成功后只推进g0产生的R1 |
| 训练 | 每任务50epochs；batch128，保留尾批；SGD momentum0/weight_decay0 |
| 学习率 | task0 .04，后续.02；cosine T_max50，最低LR比率.1 |
| 数值 | FP32、math attention、AMP/TF32off、严格确定性、eps1e-12 |
| 新变量 | 仅最终方向为g0+(g0−g−)，ρ=.05，修正系数1 |
| 禁用 | EWC/Fisher/阻尼/归一化Fisher/权重融合/SGV/投影/额外最终梯度归一化/HVP/create_graph/replay数据 |

不对主P/C/CD队列的代码、配置、状态或现有进程做改动。新实验仅物理GPU0，最多1个作业；共享已有编号/UUID锁，实时双次检查空闲<500MiB且利用率<10%，不抢占其他进程。旧队列可继续在GPU1完成CD及后续诊断，实际资源分配由既有共享锁控制。

| 阶段 | 内容 | 放行要求 | 预算 |

## 指标与判断

主指标十阶段任务等权AAA；同时FAA、LA、BWT、遗忘、逐任务矩阵与最终逐样本准确率。日志记录训练CE、g0/g−/修正/U范数、cos(U,g0)、cos(g0,g−)、修正/g0比率、实际负侧参数距离、LoRA BA+FC有效位移、每步梯度/更新数量及恢复结果。诊断只使用已算梯度，不添加前向或反传。

第一问题：该两探针更新能否完成稳定训练并得到完整CL结果？第二问题：在同协议对照补齐后，符号修正直接回加是否优于仅g−，以及是否接近或改善SAM？本轮只有一个新正式设置，先得到完整结果。历史native attention与四探针基线只作背景，不直接作为严格同协议优势证据；若需要论文中的因果比较，后续再做math后端、相同两探针状态/RNG协议的g0、g−、g+对照，并固定预算口径。

单seed只作探索；若结果接近SAM，支持一阶修正方向解释；若不同，可能涉及有限半径非线性、修正幅值与学习轨迹，不能立即归因于Hessian机制。若结果变差，首先检查已记录的修正/g0比率和有效步幅；本轮不自动扩展系数/半径扫描。
