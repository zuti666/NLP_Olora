## 数据口径

**B1** 使用正式ImageNet-A的seed0。损伤/准确率使用1259张训练图、50个公共方向，每方法107个半径；raw Fisher使用固定256张训练子集、16个公共方向，每方法42个半径。曲线无跨seed误差带。第一幅标注正部 `Loss overline([D_0]_+)`，即各方向的旧任务平均CE锚点差值先取正部、再对方向平均；它不是带符号损失变化。

B1第四幅沿用同一损伤曲线，计算前缀安全的最大已测容忍半径，阈值覆盖0.005、0.01、0.02、…、0.10，未插值。r=21–24仍缺测；20与25之间只有相邻实测点的连线，没有新测量标记。网格缺口会影响容忍半径平台。r=17的实测Fisher尖峰保留。

**B2** 使用正式ImageNet-A三seed。前三幅包含T=1–10共60个端点，末幅包含T=2–10的54条独立Task0→Taskt直线段；T=1路径敏感度未定义，不绘零。曲线均值及阴影来自三个训练seed的均值±样本标准差（ddof=1）。最后一幅先在每个seed计算方向Fisher沿端点直线段的积分除以位移平方，再跨seed平均；它不是端点trace，也不是优化器全部训练步骤的积分。

两图样式一致，但B1为seed0、B2为三seed。数据批次没有混成历史ImageNet-R。
