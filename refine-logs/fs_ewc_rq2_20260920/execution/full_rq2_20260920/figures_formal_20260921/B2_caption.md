Figure B2. Formal three-seed sequence diagnostics on ImageNet-A. From left to right: effective Q/V weight drift $r_T=\|\Delta_T\|_2$ from each method's own Task0 anchor; signed Task0 test cross-entropy damage $D_T^{\mathrm{test}}=L_0^{\mathrm{test}}(w_T)-L_0^{\mathrm{test}}(w_1)$ (including negative changes); Task0 test accuracy; and chord-normalized directional empirical-Fisher sensitivity (``Average Fisher'') $S_T=I_T/r_T^2$, where $\Delta_T=w_T-w_1$ and $I_T=\int_0^1\Delta_T^\top F_0^{\mathrm{emp}}(w_1+s\Delta_T)\Delta_T\,ds$. Here $T=t+1$ is the number of learned tasks; $T=1$ denotes the Task0 anchor. The first three panels include all ten measured endpoints $T=1,\ldots,10$. Test loss and accuracy use all 307 Task0 test examples and each method's fixed 20-class Task0 head. $F_0^{\mathrm{emp}}$ is the unnormalized, true-label, per-example empirical Fisher over all 1,259 Task0 training examples in the 24 effective Q/V matrices; Average Fisher is the normalized directional integral, not a Fisher trace. Each sensitivity estimate integrates its own straight chord from the anchor using nine measured Simpson nodes, with the five-/nine-node stability and numerical bound checks passed. Path measurements exist only at $t=1,5,9$ ($T=2,6,10$); the connecting segments are visual guides and represent no additional measurements. $S_1$ is undefined because $r_1=0$ and is omitted. All curves show arithmetic means across three training seeds (0, 1, 2); bands in the first three panels and error bars at the three measured path stages show sample standard deviations ($n=3$, denominator $n-1$).
