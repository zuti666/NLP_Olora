# 新增 B1 四子图版本：训练邻域与经验容忍半径

[查看 PNG](Figure_B1_neighborhood_with_tolerance.png) · [矢量 PDF](Figure_B1_neighborhood_with_tolerance.pdf) · [完整英文图注](CAPTION.md)

本目录沿用原三子图的 Times New Roman、颜色、线型和紧凑布局，新增第四项训练集容忍半径，并独立保存为新结果。原三子图及 B2 的 PDF、PNG、数据和说明文件均保留；绘图脚本运行前后逐文件核对旧版本 SHA-256，确认未变。

数据仍是正式 ImageNet-A 三个训练 seed（0/1/2）、ViT-B/16 rank-10 Q/V LoRA 的 Task-0 端点。前三项的数值没有更改：训练平均正损伤、训练准确率、训练子集 raw Fisher trace。前两项使用全部 1,259 张训练图、100 个配对方向和 81 个半径；Fisher 使用固定 256 张训练子集、16 个方向和 7 个半径。第四项完全派生自第一项的逐 seed 损伤数据，没有新 GPU 评估。

## 原始数据到底保存了什么

每个方法、每个训练 seed 的 `dense/summary.json` 包含：

- `radius_summary`：每个半径的 `D_each`（100 个方向各自的有符号损伤）、`G`（平均正损伤）、`D_mean`（平均有符号损伤）、`absolute_loss_mean`（平均绝对 CE）及准确率等。半径为 0–20、步长 0.25；原点只评估一次。
- `tolerance`：预先保存的五个允许损伤阈值 `epsilon = 0.001, 0.005, 0.01, 0.02, 0.05` 下，训练/测试的 `G`/`Q95` 容忍半径和右删失标记。
- `states.jsonl`：每个半径、每个方向的原始评估状态、实际损失、样本数和方向哈希。

所以，**每个半径对应的是实测损伤 G(r)，并不是“每个半径都有一个固定 epsilon=0.01”**。epsilon 是后续读取损伤曲线时选定的允许损伤预算，可以利用已保存的 G(r) 计算其它阈值，无需重新跑模型。改变阈值不会增加半径或方向上的测量覆盖。

## 为什么第四图这样画

第四项横轴为允许的平均正 CE 增量 epsilon，纵轴为经验容忍半径。先对每个 seed 的 G(r) 取前缀最大值，再反求所有更小已测半径都满足阈值的最大网格点。每个 seed 的半径只取 0.25 网格值；三 seed 均值未必是 0.25 的整数倍。

图中采用原始 G 值构成的全部阈值转折点，画**精确阶梯函数**。没有把五个预设阈值用平滑曲线连接，也没有对半径插值。三个 seed 先分别反求半径，再求均值及样本标准差；不能先平均 G 再反求半径。

- 横轴完整展示 0–0.05，使用线性刻度。
- 圆点/菱形标出已保存的 0.001、0.005、0.01、0.02；竖虚线及误差棒强调 0.01。
- 水平虚线标出扫描上限 20。到 0.05 时，两个方法的三个 seed 均扫描到 20 而未找到失败点；共同的向上箭头表示右删失。不能将这段平台解释成真实容忍边界相同。
- 阴影和误差棒为三个训练 seed 的样本标准差，不是球内保证、方向间标准差或置信区间。未裁剪的均值±SD 阴影是描述统计，其边缘不是可取半径边界。

第一项问“给定半径，损伤多少”，第四项问“给定损伤预算，可接受的已测半径多大”。两者是同一批测量的正向读取与前缀包络的离散反求；第四项用于解释实际损伤预算，不作为独立机制证据计数。

## 训练与测试的区别，以及原点损失

在 epsilon=0.01 时，训练半径的三 seed 均值为 EWCLoRA 10.5833、FS-EWCLoRA 12.1667；测试均值为 6.9167、6.0000。测试半径在三个 seed 上均较小。B1 四项保持训练侧口径，测试结果保留在 [核验说明](DIRECTION_AND_BASELINE_AUDIT.md) 和 [训练/测试阈值表](saved_G_tolerance_train_and_test.csv)。

G(r) 先用各方向上的平均 CE 减去同一模型自己的原点 CE，再对差值取正部，最后平均 100 个方向。两方法使用同一方向库、相同扰动坐标和相同绝对范数 r，但从各自不同的模型端点出发；并不是使用同一个参数点。

“相对原点增加多少”和“扰动后绝对损失多大”是两个不同问题。更低的原点 CE 可以与更大的损失增量共同出现，使最终绝对 CE 仍然较低。原点 CE 低本身并不必然造成 G 更大，也不能据此把测试容忍半径反向解释为更大。若改成共同绝对 CE 上限，那会得到另一个同时受初始性能影响的指标，不能悄悄替代现有相对损伤半径。

完整实测值、方向配对的逐状态核验和原始路径见 `DIRECTION_AND_BASELINE_AUDIT.md/.json`。这里的容忍范围只针对有限随机方向、有限半径网格和平均正损伤；不代表所有方向均满足阈值。
