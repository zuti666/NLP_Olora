## 数据与统计口径

- seed0 单 seed；两方法使用公共随机方向。模型为 ViT-B/16、rank-10 Q/V LoRA，当前正式 ImageNet-A 数据配置，固定 Task-0 锚点与旧任务 20 类输出头。此图不是历史 ImageNet-R 实验。
- 损伤与准确率：50 个方向，全部 1259 张旧任务训练样本；旧点从逐方向原始记录截取同一前 50 个方向重新聚合。Fisher：16 个方向、固定 256 张旧任务训练样本。
- 前两图网格为 0–20、步长 0.25，加上 25–50、步长 1，共 107 个半径。第三图为 0、0.5、1、2、5、10–20 的整数、25–50 的整数，共 42 个半径。
- 25–50 整数点全部完成；21、22、23、24 不属于已完成网格。曲线间连线仅作视觉引导，不能当成额外测量。
- Fisher 是 true-label、per-example CE 梯度平方范数的样本均值，再对方向求均值；未乘 EWC 的 lambda，未做 trace 或参数量归一化。
- 单 seed 不显示跨 seed 误差带；保持 Times New Roman、一行四图、一致颜色与线型、图内 legend。无测试曲线。

损伤定义：G(r) = mean_k max(L_train(theta + r u_k) - L_train(theta), 0)。L_train 是平均每张样本的交叉熵；先在每个方向上对样本平均，再取损伤正部，最后对 50 个方向求平均。图中文字使用平均损失变化符号，实际统计仍是该平均正损伤。

## 容忍半径

第四图从各方法损伤曲线的前缀最大值反求阈值：保留最大已测半径，使它及所有更小的已测半径满足 G <= epsilon。它是损伤曲线的阈值读数，不是独立机制证据，也不保证球内所有方向均安全。

| epsilon | EWCLoRA 最大通过 / 首个失败半径 | FS-EWCLoRA 最大通过 / 首个失败半径 |
|---:|---:|---:|
| 0.005 | 8.25 / 8.5 | 9.25 / 9.5 |
| 0.01 | 11 / 11.25 | 12.25 / 12.5 |
| 0.02 | 14.5 / 14.75 | 16.25 / 16.5 |
| 0.04 | 19 / 19.25 | 20 / 25 |

epsilon=0.04 时 FS-EWCLoRA 的已测通过半径是20，首个失败点是25；20已不是扫描上限，扫描上限为50，但21–24尚未测量。因此图中20是已测网格统计，不是精确连续阈值。

## 解释与限制

本 seed0 训练邻域中，FS-EWCLoRA 在所有已测非零半径上平均正损伤更低，所有已测点训练准确率更高、Fisher 更低。扩展至50后，两方法均出现明显损伤和准确率下降。该图支持此 seed 的训练邻域比较，不能推断测试保护区域或跨 seed 稳定性。

第三图 r=17 的 EWCLoRA 尖峰保留原始均值：16方向中 direction14 的 trace 较高，属于已保存的有限值测量，不是绘图插值或 CSV 聚合产生。没有额外重跑来判定该方向尖峰的复现性。
