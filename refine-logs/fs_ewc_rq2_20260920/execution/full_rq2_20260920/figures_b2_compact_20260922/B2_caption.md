Figure B2. Formal three-seed sequential diagnostics on ImageNet-A. From left to right: Task0 test accuracy; signed Task0 test cross-entropy change relative to each method's own Task0 anchor; effective Q/V weight drift from that anchor; and normalized directional path sensitivity (``Average Fisher'') $\overline S_{\mathrm{path},t}=\int_0^1\Delta_t^\top F_0^{\mathrm{emp}}(W_0+s\Delta_t)\Delta_t\,ds/\|\Delta_t\|_2^2$, with $\Delta_t=W_t-W_0$. The horizontal coordinate is the number of learned tasks $T=t+1$. The first three panels contain all ten measured endpoints $T=1,\ldots,10$. Loss and accuracy use all 307 old-task test examples and the fixed 20-class Task0 head. The last panel contains independently measured anchor-to-endpoint straight chords for every $T=2,\ldots,10$, with no estimate at $T=1$ because the denominator is zero. Each chord's empirical Fisher uses all 1,259 old-task training examples, true-label per-example gradients in the 24 effective Q/V matrices, and no EWC coefficient, trace normalization, floor, or regularization. Adaptive nested Simpson quadrature used 9, 17 measured nodes per chord; all final stability and numerical-bound checks passed. Integration nodes are positions along a chord, not task stages; these chords are not the optimizer's chronological path. Curves show arithmetic means over the three independent training seeds 0, 1, and 2. Standard-deviation shading is omitted in this presentation; sample standard deviations (denominator $n-1$) remain available in the accompanying CSV. Sensitivity uses each seed's own normalized integral before aggregation and is not an endpoint Fisher trace. The original 18 paths at $t=1,5,9$ are reused; 36 new paths fill $t=2,3,4,6,7,8$.

The third-axis symbol delta denotes the magnitude of the effective Q/V displacement; all four panels include internal method legends. The labeled y-axis ranges are unchanged from the shaded version; this figure displays mean curves only.

Panel titles are Accuracy, Loss change, Weight drift, and Average Fisher. The fourth panel uses an upper-left method legend.

Compact-layout revision: each subplot title is 10.5 pt and horizontal subplot spacing is reduced from wspace=0.56 to 0.38. The third axis uses $\delta_t=\|\Delta_t\|_2$ and the fourth axis explicitly displays $\overline S_{\mathrm{path},t}=I_t/\delta_t^2$, where $I_t$ is the directional Fisher integral defined above. The axis equation denotes the per-seed metric; each plotted point is the arithmetic mean of these individually normalized metrics across three seeds, not a ratio of aggregate quantities. The overbar in the metric name denotes the path average.
