**Figure C.** Existing ImageNet-A sequences (seed 0), evaluated in full FP32. Learning stage $T=t_{\mathrm{code}}+1$ counts learned tasks: $T=1$ is the Task0 anchor and $T=10$ follows Task9. EWCLoRA uses SGD at Task0 and SGD+EWC thereafter; FS-EWCLoRA uses GAM at Task0 and GAM+EWC thereafter, so subsequent optimizers differ. (a) Actual displacement $r_T=\|W_{T-1}-W_0\|_2$ from each method's own anchor, in the joint coordinates of 24 effective Q/V $BA$ matrices (scaling 1). (b) Signed Task0 test cross-entropy change $D_T=L_0^{\mathrm{test}}(W_{T-1})-L_0^{\mathrm{test}}(W_0)$; negative values indicate improvement. (c) Task0 test accuracy. Both test metrics use the same 307 examples and fixed 20-class Task0 head. Lines join all measured checkpoints; negative and nonmonotonic changes are retained. (d) Final chord-normalized sensitivity $\bar S_{10}=I_{10}/r_{10}^2$, with $I_{10}=\int_0^1\Delta W_{10}^{\top}\widehat F_{\mathrm{emp}}(W_0+s\Delta W_{10})\Delta W_{10}\,ds$ and $\Delta W_{10}=W_9-W_0$. The raw empirical Fisher averages outer products of unscaled per-example CE gradients on 256 stratified Task0 training examples, using the fixed head without trace normalization, flooring, or regularization. Nine composite-Simpson nodes evaluate only the final straight effective-weight chord, not the optimizer trajectory. This single-run comparison supplies no across-run uncertainty or isolated effect of the Task0 anchor; displacement is not a damage-tolerance radius.
