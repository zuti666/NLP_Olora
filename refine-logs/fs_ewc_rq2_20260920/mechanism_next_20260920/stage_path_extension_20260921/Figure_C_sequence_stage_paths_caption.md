Figure C. ImageNet-A, seed0. From left to right: actual joint effective-Q/V displacement $r_T=\|\Delta_T\|_2$, where $\Delta_T=w_T-w_1$, from each method's own Task0 anchor; signed Task0 test cross-entropy change relative to that same anchor; Task0 test accuracy (%); and average Fisher sensitivity. The loss and accuracy panels use each method's fixed Task0 20-class head on all 307 Task0 test examples. The rightmost panel's Average Fisher denotes chord-normalized directional empirical-Fisher sensitivity, $\bar S_T=I_T/r_T^2$, where $I_T=\int_0^1\Delta_T^\top F_0^{\mathrm{emp}}(w_1+s\Delta_T)\Delta_T\,ds$, and $F_0^{\mathrm{emp}}$ is the unnormalized, true-label, per-example empirical Fisher on the same fixed 256 Task0 training examples for every stage. T is the number of learned tasks, with T=1 denoting Task0. Each sensitivity point integrates a separate straight chord from Task0 to that checkpoint, not the optimizer-step trajectory. Adaptive Simpson quadrature uses 9, 17, or 33 measured nodes (observed counts: 9). T1 sensitivity is undefined because $r_1=0$ and is not plotted. One seed per method; no error bars across seeds.
