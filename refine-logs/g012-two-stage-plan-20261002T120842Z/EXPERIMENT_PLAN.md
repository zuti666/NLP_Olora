# ImageNet-A：g0 / g2 两阶段机制实验计划

日期：2026-10-02；版本时间：12:08:42 UTC。状态：PLANNED_ONLY。

本轮仅设计、保存计划，没有新增训练、修改训练源码、注册队列或恢复旧队列。所有拟议条件均未运行。用户限定本轮 seed=2，不自动增加其他 seed、半径或修正系数。

## 研究问题与已有证据

研究对象为纯梯度更新，不含 EWC、Fisher、权重融合和原 GAM 正交修正。令同一模型状态、同一批次、同一前向随机函数下的梯度为 g(x)，并定义：

\[
c_{10}=g_1-g_0,\quad c_{21}=g_2-g_1,\quad
g_2=g_0+c_{10}+c_{21},\quad
U_{\mathrm{Sec}}=g_0+c_{21}=g_2-c_{10}.
\]

必须分清以下作用：

| 对象 | 在计算链中的作用 | 当前证据能说什么 |
|---|---|---|
| g0 | 普通 CE 梯度；提供第一探针方向；参与第一次差分；作为 Sec 的最终更新基底 | 不能通过单独比较 g0 与 g2，把其全部作用删掉或归因为无用 |
| c10 | 选择外层探测位置；在直接 g2 更新中还隐含作为最终加性项 | Sec 删除其最终加性项，但仍依赖它选择位置 |
| g2 | 外层位置的 CE 梯度，包含上述三个加性部分 | g2 本身不是 HVP，也不是独立的“曲率修正项” |
| c21 | 从第一探针点到外层点的跨点梯度响应 | 加回 g0 的 Sec 已有经验收益；尚需尺度控制和位置/读取算子的分离 |

已有同协议 seed2、r=.25、rho=.05 的自然步长结果：

| 最终更新 | AAA | FAA |
|---|---:|---:|
| g0 | 60.947 | 38.893 |
| g1 | 63.828 | 45.120 |
| g2 | 66.586 | 50.720 |
| Sec = g0+(g2−g1) | 66.105 | 50.531 |
| g1+(g2−g1) 的 g1 正交残差 | 65.897 | 49.418 |

Sec 相对 g0 为 +5.158 AAA / +11.638 FAA 个百分点；比 g2 低 .481 AAA / .189 FAA。它支持在当前设置下删除最终 c10 后仍保留较多收益，不能证明 c10 的位置选择作用不重要。正交残差对 g1 有帮助，也不能直接推出完整残差的收益仅来自方向；现有 Sec 的实际有效步幅约为自身状态下 g1 参考的 1.298 倍。

来源：[已完成结果核验报告](/data/140-1/users/liying/O-LoRA/refine-logs/r025-c21-ab-results-audit-20261002/REPORT.md)。

## 两个待检验的主张

| 主张 | 最少需要的证据 | 不允许跳到的结论 |
|---|---|---|
| C1：第一次差分所选择的外层位置，是 Sec 收益的重要条件 | 第一侧别/外层符号四格、直接 g2 与 Sec 分开、关键 Sec 有效步幅匹配；必要时直接 g0 定位替代 | 下降探针有效就证明第一次探针无用；有限半径一次移动就找到全局最大梯度范数点 |

## 有效步幅匹配的统一定义

自然步长为 phi_next=phi−eta*U。它回答算法在原生学习率下的表现，包含方向和幅值的共同作用。

匹配时，以各候选自己的当前状态、同批次正向 g1+ 为唯一参考，即使候选使用下降第一探针：

\[
\Psi(\phi)=\operatorname{concat}(B_1A_1,\ldots,B_mA_m,W_{\rm FC},b_{\rm FC}),
\]
\[
\delta_{\rm ref}=\|\Psi(\phi-\eta g_1^+)-\Psi(\phi)\|,\qquad
\|\Psi(\phi-\tau U)-\Psi(\phi)\|=\delta_{\rm ref},\ \tau>0.
\]

使用完整 LoRA 的有效 BA 和全部 seen FC 权重/偏置，不能仅匹配因子梯度 norm。所有分支使用同一 g1 参考数值实现。历史参考由原生 clean projector 在 gamma=0 生成，和存储的 raw g1 有 FP32差异；未来新框架必须显式选择并全组一致，不能 silently 混合。默认新框架直接采用同批次正向梯度，并通过 S+ 身份验收。

可复用历史 effective_step.py 的四次多项式求解：正区间 (0,10] 的最小正根，解析划分全部驻点，求根预测 rtol=1e−10、最多90轮，实际 FP32 BA+FC步幅相对误差≤1e−3。零目标、退化方向、无根、非有限值或实际误差超标均停止并记录失败，不回退名义LR后假称已匹配。

这是自身状态参考匹配，不能声称不同完整训练轨迹的每一步绝对运动长度相同。匹配后各层运动分配、g0与修正的比例仍可能不同。

## 实施前验收与指标

每一步探针复用同一输入、增强与前向随机实现；dropout/stochastic depth 若非零，按该步保存并复用 mask/RNG。所有离线诊断独立保存、恢复参数、buffers、梯度缓存、模式与全部RNG，不推进训练数据随机流。每批恢复基点后只提交一次 SGD；不能用全局负 rho 顺便翻转后续 GAM 探针。

具体前向RNG规则：进入该训练步保存R0，g0的一次前向后保存R1；所有其余普通探测和HVP前向均重播R0，从而使用相同mask，结束后恢复R1。下一训练步从R1继续，不能始终回到R0而让不同训练步复用同一mask。数据增强使用与方向分支无关的独立随机流；buffers也按基点快照恢复，独立诊断保存/恢复进入诊断时的状态。

新协议对所有非HVP条件统一执行 g0 → g1+ → g1− → g2m 四次CE梯度；CE/S+/S−也走同一四次探测，外点默认P，最终只选择对应方向。每次从快照精确恢复phi，复用同一前向随机实现，不执行未使用的g3、不额外重复clean CE。匹配直接复用已计算的g1+，不加一次参考探测。每条完整非HVP训练为2550×4=10200次普通CE梯度计算。历史四次GAM探测+一次clean CE为12750次，故历史不作该新协议的身份配对。HVP组同样四次普通CE梯度，另记录带create_graph的一阶计算和HVP反传次数，不伪装等计算成本。

主指标 AAA：十阶段任务等权平均。次指标 FAA、LA、BWT、Forget，保存完整下三角任务矩阵。指标定义：

\[
\mathrm{AAA}=\frac1{10}\sum_{t=0}^9\frac1{t+1}\sum_{j=0}^t a_{t,j},\quad
\mathrm{FAA}=\frac1{10}\sum_{j=0}^9a_{9,j},\quad
\mathrm{LA}=\frac1{10}\sum_{j=0}^9a_{j,j}.
\]
\[
\mathrm{BWT}=\frac1{9}\sum_{j=0}^8(a_{9,j}-a_{j,j}),\quad
\mathrm{Forget}=\frac1{9}\sum_{j=0}^8(\max_{k=j,\ldots,9}a_{k,j}-a_{9,j}).
\]

核验 FAA=LA+.9*BWT。这是描述性恒等式，不作因果中介解释。样本加权结果另列，不与任务等权混用。只有单 seed，不报告跨 seed 方差、显著性或统计等价；任务/checkpoint/batch不是独立训练重复。

诊断固定 Task0/1/4/9 的任务入口、完成第1 epoch后、任务终点。每位置固定最多2个无放回当前任务批次，允许小末批；保存样本清单。共最多12个模型状态/24个批次。主诊断在固定参考checkpoint上同状态比较全部候选；各分支实际训练状态另记录，不能混称同端点。

记录第一探针损失差、外点梯度范数变化、探针实际参数/有效BA+FC位移、g0/g1/g2/c10/c21/U范数与有符号余弦、tau/eta、有效步幅、失败计数。HVP数值诊断在验收通过后补充，不阻塞阶段1的非HVP诊断。
