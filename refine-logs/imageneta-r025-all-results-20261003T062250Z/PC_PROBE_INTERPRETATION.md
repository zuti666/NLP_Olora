# P/C反向探针与梯度范数方向：训练日志补充核验

仅分析已经完成的四条自然g2训练，未运行新实验。每条2550步，step_trace SHA256与独立完成核验证据一致。正探针每步损失均上升，负探针每步损失均下降。

| 分支 | 外点梯度范数增大的步数 | 比例 | g2 AAA / FAA |
|---|---:|---:|---:|
| P | 2549 / 2550 | 99.961% | 66.663 / 49.937 |
| D | 2 / 2550 | 0.078% | 46.887 / 24.999 |
| C | 2546 / 2550 | 99.843% | 66.647 / 49.793 |
| R | 1 / 2550 | 0.039% | 48.943 / 26.857 |

这些是各自训练轨迹内的观测，不是同一checkpoint、同一批次的四分支因果对照；2550步不能视为2550独立重复。

在同一光滑损失、g0非零条件下，u=g0/||g0||，H=∇²L(φ)：qP/ρ=(g1+−g0)/ρ≈Hu，qC/ρ=(g0−g1−)/ρ≈Hu，而D/R为反号。Hu=∇||∇L||，故P/C局部近似梯度范数上升方向。C的负侧采样和差分反号实现后向有限差分；不是两个真实optimizer更新。外点从原基点φ出发。

原SAM对邻域最坏损失作优化，GAM则引入邻域最大梯度范数；当前纯g2与跨点差分更新是代码消融，不等同于原GAM完整目标的梯度。

A_C−A_P=(g2C−g2P)+(g1+−g1−)。常H二次损失下P/C外点相同，故A_C−A_P=2ρHu，最终更新差为−2ηρHu；一般非线性和有限半径下不保证相等。

自然A_C比A_P高.859 AAA/.723 FAA；有效位移匹配后只高.006 AAA/.061 FAA。这不支持稳定宣称C优于P。

同状态梯度逐位一致性诊断与HVP门禁仍未通过。本分析只提供有条件的数学解释与逐轨迹日志证据，不是验证过的Hessian机制。
