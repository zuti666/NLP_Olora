# 阶段1：第一次差分为什么要把外层探针放在那里？

状态：PLANNED_ONLY；seed2；统一设置见 EXPERIMENT_PLAN.md。本阶段不涉及HVP训练，也不重新扫描半径。

## 固定构造与四格干预

令 u0=N(g0)，g1+=g(phi+rho*u0)，g1−=g(phi−rho*u0)，rho=.05。每次读取g1后恢复原phi；外层点一律为 phi2=phi+r*N(q)，r=.25，而不是phi1+r*N(q)。

| 分支 | 第一探针侧别 | 外层方向 q | 小rho下的外层意图 | 第一侧梯度 |
|---|---|---|---|---|
| P 原版 | + | g1+−g0 | 梯度范数上升方向 | g1+ |
| D 用户提出的直接下降 | − | g1−−g0 | 梯度范数下降方向 | g1− |
| C 下降侧符号修正 | − | g0−g1− | 梯度范数上升方向 | g1− |
| R 原版反转外层方向 | + | g0−g1+ | 梯度范数下降方向 | g1+ |

这里“上升/下降”是局部方向预测，有限r不保证范数按此变化，更不是求得球内最大值。对于固定平滑损失，g1+−g0约为rho*H(phi)u0，g1−−g0约为−rho*H(phi)u0；C与P是向同一Hu0方向的后向/前向差分，而不是完全删除第一次探针。

同状态二维因素为第一侧别a∈{+1,−1}、预期外层符号b∈{+1,−1}，可统一写 q=a*b*(g1^a−g0)。P=(+,+)，D=(−,−)，C=(−,+)，R=(+,−)。分别对 O 家族与 A 家族报告四格差值，不跨家族混成因果效应。

## 最终方向：两家族分开训练

每个分支 m∈{P,D,C,R} 定义：

\[
O_m=g_2^m,\quad A_m=g_0+g_2^m-g_1^m.
\]

O_m直接观察外层位置梯度的训练表现；A_m观察跨点修正加回基点的表现。C/D中第一侧梯度均为g1−；P/R均为g1+。

| 批次 | 条件 | 提交方向 | 数量 |
|---|---|---|---:|
| 首批自然 | CE，S+，S− | g0，g1+，g1− | 3 |
| 首批自然 | O_P，O_D，O_C | 各自g2 | 3 |
| 首批自然 | A_P，A_D，A_C | 各自g0+(g2−g1) | 3 |
| 补四格自然 | O_R，A_R | g2R；g0+(g2R−g1+) | 2 |
| 方向控制 | A_P，A_D，A_C，A_R | 同上，匹配各自状态下正向g1+有效步幅 | 4 |
| 方向控制基线 | CE | g0，同一g1+参考匹配 | 1 |

合计16条完整训练。S+匹配必须退化为名义LR身份，不另外算重复。O族与S−只有自然步长，解释包含方向和幅值；不据此宣布纯方向机制。需要O族纯方向结论时另列匹配实验，当前不自动扩充。

所有分支统一顺序 g0 → g1+ → g1− → g2m，共4次普通CE梯度。CE/S+/S−使用P外点作相同预算的旁路探测；最终不使用其g2。每次从快照恢复phi，复用同一批次/增强/前向随机函数。匹配复用g1+，无需额外参考探测。不执行未使用的g3，也不重复clean CE；这是新执行协议，需重新训练基线。

## 关键比较与可支持结论

| 比较 | 控制/改变 | 解释 |
|---|---|---|
| S+ vs S− | 第一探针侧别改变，最终只取第一侧梯度 | 第一侧梯度的直接训练差别；S−属于下降侧邻点更新，不能称普通SGD |
| O_P vs O_C | 预期外层上升不变，前向/后向采样改变 | 第一次采样侧别在外层定位中的影响；无需解释最终减去不同g1 |
| O_C vs O_D | 同下降第一探针，只反转外层符号 | 外层方向改变的作用 |
| O_P vs O_R | 同上升第一探针，只反转外层符号 | 相应上升侧外层方向作用 |
| A_P vs A_R | 减去g1+不变，仅外层符号改变 | 同一减法参照下外层方向影响 |
| A_C vs A_D | 减去g1−不变，仅外层符号改变 | 同一减法参照下外层方向影响 |
| A_P vs A_C | 外层预期上升相同，第一采样侧与减法参照同时改变 | 有差异时不能单归因前/后向曲率；需桥接 |
| A_P vs A_D | 用户直接反向方案 | 同时改变采样侧、外层符号和减法参照，是总体算法干预 |
| A_P matched vs CE matched | 同定义有效步幅，保留不同方向/层间分配 | 跨点修正收益是否只由总步幅放大解释 |

若 O_C 与 O_P 接近，而 O_D/O_R 较低，同时探针诊断确认相应梯度范数方向，支持外层方向符号比正/负侧读取更重要。若仅自然结果成立、匹配后不成立，必须报告尺度参与，不能宣布位置方向本身充分。

若 O_C≈O_P，但 A_C 与 A_P 差异较大，优先拆分最终减法参照；不能立即解释为一阶Hessian近似误差。若下降D也有效，说明该完整替代可以有效，不说明c10定位信息已被删除。

所有≈只表达该seed观察差小，不作统计等价声明。报告AAA/FAA差值、LA与BWT，避免预设全部收益都是抗遗忘。

## 条件补充，不计入16项核心

### 减法参照桥接

若上述O族与A族模式不一致，补：

\[
A_D^{ref}=g_0+g_2^D-g_1^+,\quad
A_C^{ref}=g_0+g_2^C-g_1^+.
\]

同状态 A_D−A_D_ref=A_C−A_C_ref=g1+−g1−。保持各自外层位置，固定减去g1+，拆分参照点影响。先自然2条，需要方向解释再匹配2条；完整预算不自动包含。

### 真正替代 c10 的定位信息

\[
\phi_2^{grad}=\phi+rN(g_0),\quad
A_{grad}=g_0+g(\phi_2^{grad})-g_1^+.
\]

这是不使用c10选位置的对照；仍使用g0与g1+作为构造/参考。原A观察到更高结果，且匹配后差异仍保留，才增强“第一次差分定位有特异价值”的证据；相近则这一特异性未建立。自然/匹配2条，条件附加。

不能令r=0后把A称SGD：此时A=2g0−g1。不能把first_probe_sign=-1等同全局gam_grad_rho=-.05，后者可能翻转另一内层探针并引入第二干预。

## 数值验收与诊断

未来实施前，CPU float64二次函数检验：

- 符号：c10+=rho*Hu0，c10−=−rho*Hu0；phi2P=phi2C、phi2D=phi2R。
- 区分“同位置”与“同最终方向”：即使二次函数上P/C外点相同，A_P与A_C仍减去不同g1，所以不能验收为A_P=A_C。
- 全部分支恢复原基点，只执行一次SGD，关闭Fisher/权重融合的实际调用数为0。
- 正参考g1+在所有分支相同定义；S+自然/匹配更新身份通过；有效几何范围完整。
- 退化c10≈0使用统一N规则，记录频次，不依据测试准确率换阈值。

记录 DeltaL1±=L(phi1±)−L(phi)，DeltaG2m=norm(g2m)−norm(g0)，以及各探针实际位移、有符号cos(qP,qC)、cos(qD,qR)、c21与g0/g1的范数比。h0=H(phi)u0的离线前/后差分误差在HVP通过后记录；不能使用绝对余弦掩盖相反符号。
